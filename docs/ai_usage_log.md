# AI Usage Log

**Project:** ConferenceCheck Mobile: Analytics, Meals and Notifications (component 4.3b)
**Student:** Ndashi Bwalya Chisanga (2021470105) · **Supervisor:** Mr. Mofya Phiri

This log supports the disclosure required by Section 9 of the approved
proposal and reproduced as Appendix A of `docs/paper/conferencecheck-paper.md`.

## Status of this log

The proposal (Section 9.4) commits to a dedicated log recording each
instance of AI use: the tool, the date, the task posed, a summary of the
output, and the extent to which it was used, modified or rejected. That
per-episode log was **not maintained contemporaneously** during development.
This file is a retrospective, honest statement of that gap, plus the
scope and validation commitments the proposal placed on AI assistance —
it is not a reconstruction of a per-episode record, because reconstructing
specific dated entries after the fact with invented detail would be less
honest than stating plainly that the contemporaneous log does not exist.

## What AI assistance was scoped to (Proposal §9.1–9.2)

- Boilerplate generation for data models, REST client wrappers and test
  scaffolding, where the design remained the student's own.
- Proofreading and clarity improvements to written documentation, without
  altering analytical content or conclusions.
- Clarifying questions about library APIs and language syntax.

AI tools were not used to design the voucher redemption protocol, the
capacity alerting rules, the evaluation methodology, or the interpretation
of evaluation results, as these constitute the project's academic
contribution.

## Validation applied to AI-assisted output (Proposal §9.3)

- Automated testing (Pest/PHPUnit for the API, `flutter test` for the
  client), with test cases designed independently of any AI suggestion.
- Manual trace-through of business-rule logic against known input-output
  pairs.
- Cross-referencing against official library documentation.

## What was, and was not, provided to any tool

No respondent or attendee data belonging to a real person or a third party
was provided to any external tool at any point. All evaluation data is
seeded and synthetic, generated by `tools/seed-evaluation-event.php`.
Material provided to tools was limited to project source code, project
documentation drafts, and error/test output, all of which are the student's
own and already public in the repository.

## Recommendation for remaining work

Any AI assistance used between the date of this entry and final submission
should be logged here per-episode (tool, date, task, outcome) so that the
gap described above does not extend further.
